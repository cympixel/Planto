# Planto

Planto — интернет-магазин растений на JavaScript (ES-модули). Каталог и слайдеры товаров динамически рендерятся скриптом, добавлен поиск с подсказками на Fuse.js, корзина с подсчётом суммы и переходом к оформлению заказа, слайдеры на Swiper. Вёрстка по БЭМ, адаптивные изображения в WebP с фолбэком, ленивая загрузка, ARIA-атрибуты для доступности.

Стек: HTML5, CSS3 (БЭМ), JavaScript (ES Modules), Swiper, Fuse.js.

https://cympixel.github.io/Planto/
